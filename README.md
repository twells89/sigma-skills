# Sigma Claude Code Skills

Claude Code CLI skills for migrating analytics to Sigma.

## Skills

### `tableau-to-sigma`
Converts a Tableau datasource into a Sigma data model, then builds a Sigma workbook mirroring the Tableau dashboard layout.

### `custom-sql-to-data-model`
Scans Sigma workbooks for custom SQL elements and promotes them into proper Sigma data models, then repoints the source workbook.

## Usage

These are Claude Code skills. Place them in your `.claude/plugins` directory or reference them via the `sigma-computing` plugin marketplace.
